SKYBOOK - SIMPLE ONLINE FLIGHT RESERVATION SYSTEM
Internet Programming Lab Mini Project

TECHNOLOGIES
- HTML
- CSS
- JavaScript
- Browser localStorage

HOW TO RUN
1. Extract the ZIP file.
2. Open the FlightReservationSimple folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. Choose a route, departure date, and travel class, then click Find Flights.
5. Click Book flight, enter passenger details, and click Book & Pay.
6. Your demo ticket appears under My Tickets. Print or cancel it there.
7. Admin Report shows bookings saved in the current browser.

IMPORTANT LIMITATIONS
This is a simple frontend educational demo. Payment is simulated, not real. It does not connect to airline systems, send actual email confirmations, or provide secure user accounts. Bookings are stored only in the current browser using localStorage. Sample flight availability is not live airline inventory. Do not enter sensitive personal or payment information.
