UNIT II - CLIENT SIDE PROGRAMMING
JavaScript beginner sample programs as Notepad (.txt) files

HOW TO USE:
1. Download and extract the ZIP file.
2. Open any .txt file in Notepad.
3. For HTML programs: select all code and copy it.
4. Open Notepad, paste the code, then choose File > Save As.
5. Save with the exact filename shown in the first line of each file, e.g. example1.html.
6. In Save as type, select All Files (*.*). Keep UTF-8 encoding.
7. Double-click the saved .html file to open it in your browser.
8. JavaScript-only examples (.js) can be tested by putting the code inside an HTML <script> section or by linking the .js file from an HTML page.
9. SQL examples must be run in MySQL/phpMyAdmin, not directly in a web browser.
10. HTTP request examples need an internet connection.

Each topic has a short definition and beginner examples.
