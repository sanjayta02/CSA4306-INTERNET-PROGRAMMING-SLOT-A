PROGRAM 17: CSS ANIMATION
Aim: Animate a box by changing its background color and position.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS Animation</title>
    <style>
        .box {
            width: 100px;
            height: 100px;
            position: relative;
            background-color: red;
            animation: colorMove 4s infinite alternate;
        }
        @keyframes colorMove {
            0% { background-color: red; left: 0; }
            50% { background-color: yellow; left: 100px; }
            100% { background-color: green; left: 200px; }
        }
    </style>
</head>
<body>
    <h1>CSS Animation Example</h1>
    <div class="box"></div>
</body>
</html>

Expected result: The box changes color and moves horizontally repeatedly.
