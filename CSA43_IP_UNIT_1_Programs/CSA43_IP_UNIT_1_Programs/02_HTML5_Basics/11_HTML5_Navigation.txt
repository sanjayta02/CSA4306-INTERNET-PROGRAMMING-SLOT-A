PROGRAM 12: HTML5 NAVIGATION ELEMENT
Aim: Create navigation links using the nav element.

<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Navigation Example</title></head>
<body>
    <header><h1>My Website</h1></header>
    <nav>
        <a href="#home">Home</a> |
        <a href="#about">About</a> |
        <a href="#services">Services</a> |
        <a href="#contact">Contact</a>
    </nav>
    <main>
        <section id="home"><h2>Home</h2><p>Welcome to the website.</p></section>
        <section id="about"><h2>About</h2><p>This is a sample website.</p></section>
        <section id="services"><h2>Services</h2><p>We provide web development services.</p></section>
        <section id="contact"><h2>Contact</h2><p>Email: info@example.com</p></section>
    </main>
</body>
</html>

Expected result: Clicking a navigation link moves to the corresponding section.
