# Smart Library Management System - Pure HTML Version

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

No Python, Flask, Node.js, MySQL, or server is required.

## Run
1. Extract the ZIP.
2. Double-click `index.html`.
3. The application opens directly in your browser.

## Data
All data is stored in the browser's LocalStorage. This makes the project easy to demonstrate without a backend. For real multi-user deployment, replace LocalStorage with a server/database.
