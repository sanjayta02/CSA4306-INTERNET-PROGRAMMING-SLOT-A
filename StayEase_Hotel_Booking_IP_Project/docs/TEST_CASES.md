# Test checklist

- [ ] Open `index.html` and confirm all navigation links work.
- [ ] Test at desktop width and a narrow mobile width.
- [ ] Create a demo account with a unique email.
- [ ] Try registering the same email again.
- [ ] Log out and log in with the account.
- [ ] Update the profile name and phone.
- [ ] Try a valid future booking.
- [ ] Try checkout on/before check-in.
- [ ] Try guests above room capacity.
- [ ] Create overlapping bookings until the sample quantity is reached.
- [ ] Check customer change/cancellation when arrival is 3+ days away.
- [ ] Check customer change/cancellation when arrival is fewer than 3 days away.
- [ ] Update room rates and quantities in `admin.html`.
- [ ] Edit and cancel a booking as admin.
- [ ] Edit the FAQ/travel/privacy text and refresh the relevant pages.
- [ ] Check contact form demo message.
